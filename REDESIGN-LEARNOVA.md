# Learnova UI Redesign

Pembaruan visual pada dashboard siswa dengan referensi desain yang dikirim:
- Identitas Learnova dengan palet lavender, soft blue, putih, dan deep purple.
- Sidebar terang dan navigasi aktif berwarna lavender.
- Header dashboard dan hero sambutan dengan maskot robot 3D.
- Kartu ringkasan, panel aktivitas, dan progress memakai permukaan putih serta bayangan lembut.
- Seluruh data dashboard dan tautan fitur yang sudah ada tetap menggunakan sumber data LMS.

Maskot disimpan di `public/learnova-mascot.png`.

## Menjalankan proyek
1. Ekstrak folder proyek.
2. Jalankan `npm install`.
3. Siapkan variabel lingkungan/database seperti konfigurasi proyek sebelumnya.
4. Jalankan `npm run dev`.
